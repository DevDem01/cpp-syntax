Lab 5 - MyString

Compile from the repository root with:

g++ -std=c++17 -Wall -Wextra -pedantic labs/lab5/Mystring.cpp labs/lab5/main.cpp -o build/lab5.exe

Run from the repository root with:

.\build\lab5.exe

The implementation manually counts and copies characters. It does not use
std::string, strlen(), or strcpy(). The test program covers the required
operations, the copy constructor, and copy assignment.
