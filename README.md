# C++ Syntax & Practice

A personal C++ learning repository for practicing core syntax, programming fundamentals, and object-oriented programming concepts.

This repository contains small programs, coding exercises, and examples created while learning C++ and preparing for more advanced coursework in object-oriented programming.

## Topics Covered

- Variables and data types
- Input and output with `cin` and `cout`
- Conditional statements
- Loops
- Functions
- Arrays and vectors
- Strings
- Pointers and references
- Classes and objects
- Constructors and destructors
- Encapsulation
- Inheritance
- Polymorphism
- STL containers
- Basic algorithms

## Practice Programs

Examples in this repository may include:

- Grade calculator
- Number analyzer
- Rock Paper Scissors
- Basic calculator
- Loop exercises
- Function practice
- Object-oriented programming exercises

## Compiling and Running

This repository uses the GNU C++ compiler (`g++`).

## Repository Layout

- `lessons/` contains the lecture examples.
- `exercises/` contains standalone practice programs.
- `labs/` contains lab work, grouped by lab number.
- `projects/` contains larger projects such as the MLP example.
- `build/` contains compiled executables.

Compile and run an exercise from the repository root:

```powershell
g++ exercises/fizzBuzz.cpp -o build/fizzBuzz.exe
.\build\fizzBuzz.exe
```
