## Rock Paper Scissors 
This is explaining Rock Paper Scissors within this folder the first task was to create a rock paper scissors 
game that takes the input from the user once the input is set to a variable the stdlib.h library was used for the random number 
generator function rand().This function was divided using the modulos operator to provide a random number within a given range.
That would then be the computers selection once selected input from the computer and user was set I then set multiple conditional statements 
to print out to the user if they meet the conditions that would beat the computers random selection else I would return to the user that
their selection was not a winning selection.

##FizzBuzz
This is explaining FizzBuzz within This folder The task was to output a certain output when conditions were meet.
Output Fizz if the current number was divisible by 3, Buzz if the output was divisible by 5,Fizzbuzz if the output was
divisible by both,and print the number itself if the number does not meet the given conditions.To do so we loop from the 
given starting number from the user then up to 50 and evaluate each number up to that point by using conditional statements.
The order in which you place the conditional  statements does matter because the code runs from top to bottom so the 
code will output correctly.I added new lines to each output for readability for the user.
